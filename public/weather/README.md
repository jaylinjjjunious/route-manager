# Weather Artwork Assets

This directory hosts transparent 3D dimensional weather artwork PNG assets for the first-card weather badge.

## Expected Asset Files

| Semantic State | Expected Filename | Description |
|---|---|---|
| `sunny` | `sunny.png` | Realistic 3D sun |
| `mostly-sunny` | `mostly-sunny.png` | Sun with small cloud |
| `partly-cloudy` | `partly-cloudy.png` | Sun with clouds |
| `hazy-sun` | `hazy-sun.png` | Sun with atmospheric haze/warm glow |
| `very-hot` | `very-hot.png` | Intense/radiant 3D sun |
| `cloudy` | `cloudy.png` | Dimensional clouds |
| `overcast` | `overcast.png` | Heavy overcast clouds |
| `light-rain` | `light-rain.png` | Clouds with gentle rain |
| `heavy-rain` | `heavy-rain.png` | Clouds with heavy downpour |
| `thunderstorm` | `thunderstorm.png` | Storm cloud with lightning |
| `snow` | `snow.png` | Clouds with snowflakes |
| `heavy-snow` | `heavy-snow.png` | Clouds with dense snow |
| `sleet` | `sleet.png` | Mixed ice/rain precipitation |
| `fog` | `fog.png` | Dense low-lying fog/mist |
| `windy` | `windy.png` | Wind swirls with cloud |
| `clear-night` | `clear-night.png` | Realistic 3D moon |
| `partly-cloudy-night` | `partly-cloudy-night.png` | Moon with clouds |
| `cloudy-night` | `cloudy-night.png` | Nighttime cloud cover |
| `sunrise` | `sunrise.png` | Golden morning horizon/sun |
| `sunset` | `sunset.png` | Vibrant dusk horizon/sun |

All assets should have transparent backgrounds and be sized around 256x256 or 512x512 pixels.
When an asset is absent or loading, the application automatically displays a polished Lucide icon fallback.
